# Frenet 稳定性与曲率分离：第二轮探索实验

这轮在第一轮测试结果已被检查后开展，属于探索性开发，不是新的独立确认实验。沿用相同来源划分、真实初始状态、未来记录动作、原始位置真值与 100 步评价。不能据此宣称未见道路泛化。

## 实验矩阵

每个方向 3 个随机种子，每个种子训练下列 6 个动力学模型，每个模型从零开始训练 40 epochs、训练 horizon=32、batch=128、Adam lr=0.001、余弦学习率，统一验证 E100 选模。

| 名称 | 动力学 | 曲率 | 位置读出道路形状 |
|---|---|---|---|
| legacy_full | 第一轮原实现 | 冻结视觉预测 | 冻结视觉预测 |
| legacy_shape | 第一轮原实现 | 训练、验证、测试均置零 | 冻结视觉预测 |
| guarded_full | 数值保护组合 | 冻结视觉预测 | 冻结视觉预测 |
| guarded_shape | 数值保护组合 | 训练、验证、测试均置零 | 冻结视觉预测 |
| guarded_none | 数值保护组合 | 始终置零 | 直线；初始道路 d/psi 也置零 |
| guarded_oracle | 数值保护组合 | 真实初始道路预览 | 真实初始道路预览 |

第一轮的运动学和无道路 Cartesian 作为固定参考，不参与本轮选择。所有视觉版本使用对应方向／种子的同一个既有冻结 CNN。动力学从零训练，但没有重新训练“只监督形状、不监督曲率”的视觉编码器；因此这里只隔离动力学和读出通路。

oracle 是带特权信息的诊断参考，不是可部署的相机性能，也不保证数学意义上必定优于其他版本。它在训练、验证、评估中使用一致的信息条件。

## 数值保护组合的准确含义

1. 用 `max(1-d*kappa, 0.2)` 替代原先的符号保留保护，避免跨越零点时的正负跳变。该处理是坐标域外的数值延拓，不表示坐标仍物理有效；每个 epoch 记录原始分母不大于零的比例。
2. 把道路相对航向 wrap 到周期区间，避免等价角度在网络中形成任意不同的数值。
3. 速度和角速度增量采用 `limit*tanh(raw/limit)`，原点附近斜率为 1。limit 分别取该方向训练数据的一帧绝对增量 99.5 分位数，下限 0.01；不读取验证或测试数据确定限幅。
4. 横向与角度残差从无界的 `0.1*raw` 改为 `0.1*tanh(raw)`。

这是组合干预。即使结果改善，也不能单独归因分母、角度或某个残差头。有限的逐步增量不意味着有限时域以外的位置误差有界。未在既有旧模型文件上直接修改，也未替换第一轮结果。

## 诊断记录

- 每轮训练／验证原始分母的最小值、接近奇点与越出正坐标域的比例。
- 状态各维最大绝对值、角度超出 pi 的比例。
- 梯度裁剪前最大范数，以及触发裁剪的 batch 比例。
- 最优验证 checkpoint 与最后 epoch checkpoint 均保存。
- 所有模型完成训练后，统一打开本轮回顾性评价；全部种子保留。

比例的单位是 rollout 的 state-step 样本，不是独立轨迹失败率；相邻窗口与步数存在相关性。不能把这个比例解释为独立事故概率。

## 命令与文件

从 piwm 目录、设置 PYTHONUTF8=1 后运行：

```powershell
.venv/Scripts/python.exe scripts/check_frenet_diagnostic.py
.venv/Scripts/python.exe scripts/run_frenet_diagnostic.py prepare
.venv/Scripts/python.exe -u scripts/run_frenet_diagnostic.py jobs
```

协议已冻结后不要再次 prepare。jobs 可续跑已完成模型；已出现 results.json 后不允许重训或覆盖评价。训练进度在各 job 日志与 checkpoint 目录的 progress.json，只有 history.json 表示完整 40 epochs 已结束。修改冻结实现应另建实验并记录原因，不能直接改变文件后忽略指纹校验。

源码、固定感知器、训练统计及地图指纹见 protocol.json；模型位于 checkpoints/frenet_diagnostic/，该目录通常被 Git 忽略，需要另行备份。

模型名称：GPT-6（Codex）；当前会话未提供更细型号标识。
